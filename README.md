I'm using this page to share my Excel and Python projects. Most focus on accounting tasks, reporting, or making a dataset easier to work with.

## Projects

### [Ticket Sales Automation](https://github.com/jholbrook88/currency-weighted-average-automation)

A Python script that groups Excel ticket sales by currency and calculates total tickets, sales value, and a weighted-average ticket price. It handles inconsistent currency labels and unusable rows, then saves an Excel summary. The repo includes fictional sample data and tests.

### [Student Academic Outcomes Dashboard](https://github.com/jholbrook88/student-success-dashboard)

An Excel dashboard built from 1,000 student records. I used formulas, PivotTables, and charts to look at scores, pass rates, and differences across groups such as test preparation and lunch type.

### [Financial Reconciliation Analytics](https://github.com/jholbrook88/financial-reconciliation-analytics)

A Python and pandas project that compares a simulated bank statement with a fictional general ledger. It matches transactions and saves the remaining bank and ledger items for review. This was a way to connect my accounting background with Python.

### [Glassdoor Job Market Analysis](https://github.com/jholbrook88/glassdoor-job-analysis)

An analysis of 672 historical job postings. I cleaned up duplicates, salary text, locations, and job titles, then made tables and charts showing skill mentions and estimated salaries. The cleaned dataset has 659 postings.
